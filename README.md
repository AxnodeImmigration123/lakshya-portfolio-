# Lakshya Chauhan — Digital Marketing Portfolio

Personal portfolio website for Lakshya Chauhan.

Built from The H Portfolio community template by Ameer Hamza. The original MIT license is retained in `LICENSE`.

## Publish with GitHub Pages
Open **Settings → Pages**, choose **Deploy from a branch**, select **main** and **/(root)**, then Save.

This is a static HTML, CSS and JavaScript site; no build step is required.
